# Universal Target Utilization Shadow

The canonical numerator is unique profiles evaluated. The denominator is estimated exploitable audience with an explicit source, version, observation time and reliability; observed followers are only a fallback.

States are `healthy`, `watch`, `replacement_recommended`, `replacement_pending`, `exhausted`, `insufficient` and `stale`. The raw ratio remains visible while decision ratio is bounded. Minimum absolute volume, freshness, attribution, historical coverage and Worker-version coverage contribute to confidence.

Crossing 85% never archives a CT. It is a recommendation input only.
